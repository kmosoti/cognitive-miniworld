# ADR-022 — Tabular forward learning and transition-shift gate

**Status:** accepted · **Date:** 2026-08-28 · **Source:** MW-011

## Context

MW-011 must predict action-conditioned outcomes, remain corrigible when a
transition rule changes, and demonstrate that predictions can improve a real
decision. ADR-021 explicitly deferred asymmetric learned transitions to a new
preregistered issue. The existing `PredictionDistribution` contract already
carries normalized outcomes, provenance, horizon, and uncertainty, so this
work does not require a contract revision.

## Decision

The first forward-model family is finite and tabular. A known model requires a
complete normalized table for every configured action and source state. A
separate learned model starts each target with pseudocount `1.0` and updates
immutable counts from public belief-action-belief triples. For source exposure
`p(s)`, target evidence `p(s')`, and retention `r`, its update is
`c' = c * (1 - (1 - r) * p(s)) + p(s) * p(s')`. Thus only an experienced
source row decays, unrelated actions retain evidence, and every update returns
a new model with accumulated source-event provenance. State, action, and
horizon bounds are 64, 16, and 10,000 ticks respectively.

The confirmatory transition trace has 40 one-tick decisions and shifts at tick
20. Before the shift, `advance` toggles a binary state; afterwards it preserves
the state. The initial state comes from named stream
`experiment:transition-shift:initial-state`. Predictions are scored by the
categorical Brier rule, `sum((p_i - y_i)^2)`. Across seeds 1000–1099, learned
loss must improve by at least `0.25` over an identity model before the shift and
over the frozen pre-shift model afterwards. The active row must assign more
than `0.5` probability to the new transition within four ticks. Retention is
frozen at `0.5`.

Downstream evidence uses the canonical `delayed_poison` fixture. Two prior
episodes expose only public integrity observations at ticks 0 and 5: one
consumes once and one waits. The evaluator freezes `50.0` integrity units as
the safe/unsafe classification boundary. Those typed observations train the five-tick
consume and wait rows; their event-log hashes remain in evidence. An
evaluator-only adapter then selects the action with lower predicted unsafe
probability. Its viability AUC must strictly exceed the reactive fixed-setpoint
baseline for every paired seed. This adapter proves prediction utility but is
not the reusable action arbitrator reserved for MW-014.

## Consequences

MW-012 can consume normalized predictions without hidden world access, and a
known table remains available independently of learning. Abrupt changes are
corrigible at the cost of recency bias; changing the update equation, retention
gate, scoring rule, or confirmatory trace requires a new decision record. The
delayed test establishes one downstream win only and makes no general optimality
claim.
