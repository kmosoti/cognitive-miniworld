# ADR-025 — Public multi-objective arbitration and delayed-consequence gate

**Status:** accepted · **Date:** 2026-08-28 · **Source:** MW-014

## Context

MW-014 closes the predictive M1 loop by selecting among parallel affordances
without access to evaluator truth. The existing contracts expose action costs,
prediction distributions, typed errors, resource budgets, reference
trajectories, provenance, and uncertainty, but do not yet freeze a value rule,
an irreversible-action safeguard, or an oracle-regret gate. ADR-014 already
defines normalized squared reference deviation, so arbitration must preserve
that meaning rather than introduce a second target-loss convention.

## Decision

The first reusable arbitrator accepts one public belief, reference trajectory,
candidate tuple, one action-conditioned prediction per candidate, current
typed error, and current resource budget. All candidates share one prediction
horizon, and the reference must contain a unique point for every evaluated
variable at that horizon. For a distribution `X` and reference points `r`, its
deviation cost is the expected mean of
`((x - target) / tolerance)^2`. Reference progress is reference priority times
current deviation cost minus predicted deviation cost.

Each eligible action receives the transparent baseline value

`V(a) = progress - risk - 0.25 * cost + 0.1 * information_value`.

Risk is the maximum of declared risk relative to the budget, predicted
probability of leaving any reference tolerance, and an agency-error penalty
for an irreversible action. Cost is mean time, compute, memory, and energy
budget utilization. Information value is prediction entropy normalized by the
maximum entropy of its finite support. Time, compute, memory, declared risk,
and energy are also hard eligibility limits. An eligible irreversible action
is dominated when an eligible reversible alternative has no less progress or
information value and no more risk or cost. Dominated actions cannot win.
Remaining ties prefer lower risk, reversibility, lower cost, then canonical
action and proposal IDs.

The `ActionDecision` rationale records the four signed weighted contributions
and their exact total, where the total is defined by compensated summation
(`math.fsum`) of the four contributions; a naive left-to-right float sum can
differ in the last unit and must not be used to check it. Decision confidence combines the minimum confidence of
the selected public evidence graph with the winning value margin; normalized
choice entropy is retained separately. Provenance is the sorted union of all
public source events. Inputs are limited to 64 candidates, 64 distribution
items, 64 features per item, 64 reference points, 10,000 source-event
occurrences, and one million charged work units. Excess is rejected before
provenance union or nested scoring.

The confirmatory gate runs the canonical `delayed_poison` fixture for benchmark
seeds 1000–1099. The candidate is paired with the registered reactive fixed
set-point controller. Regret uses an evaluator-only, fully enumerated fixed
family: consume at tick zero then wait, or always wait. The evaluator runs and
retains both members before selecting the greater viability AUC, with fewer
irreversible consumes as the tie-break. The candidate must improve viability
over reactive on every seed, make no irreversible consume, incur at most
`0.03` oracle regret, incur less regret than reactive, and exhibit at least one
actual reversible-dominance case. The oracle's hidden comparison never enters
agent code or candidate inputs.

## Consequences

The decision is reproducible, bounded, and inspectable without collapsing its
distinct objectives into an unexplained reward. In the first adversarial
fixture the conservative candidate chooses the safer all-wait path, while the
evaluator oracle prefers one early consume because its energy gain outweighs
later integrity damage under viability AUC. The resulting nonzero regret is
reported rather than hidden; it is still smaller than reactive regret and the
candidate avoids the reactive controller's repeated irreversible consumes.

This baseline treats predictive entropy as potential information value and
does not estimate action-conditioned information gain. Its fixed
delayed-consequence model and static integrity reference are release-gate
adapters, not hidden access or a replacement for later learned references.
Changing weights, dominance, risk, normalization, oracle family, fixture, or
thresholds requires a new decision record.
