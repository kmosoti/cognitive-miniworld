# ADR-018 — Baseline, oracle, and paired-run boundary

Status: accepted

## Context

Milestone 0 must show that the laboratory can distinguish an ordinary policy
from a tractable upper bound without giving agent code hidden world truth. The
comparison must also survive serial and free-threaded batch execution with the
same behavioral evidence.

## Decision

Agent-side baselines receive only an `AgentScenarioView`, immutable observation
envelopes, and an explicitly named candidate RNG continuation where randomness
is required. The fixed-setpoint controller, last-observation estimator, random
curiosity, and prediction-error curiosity live under `cmw.agents`; that package
cannot import evaluator state or experiment modules.

The demand-shift oracle lives under `cmw.experiments`. It uses evaluator-only
`WorldState` to exhaust the preregistered, tractable policy family “consume at
tick 0 through horizon minus one, or never,” with a deterministic tie-break.
This is a calibration ceiling, not an agent primitive or a promotion result.

Each episode emits one evaluator state record at tick zero and at every later
tick through terminal state or horizon. The final log record is the final state
sample. Agent observations and actions occupy an explicit agent channel;
evaluator raw truth uses `actual_*` fields and never becomes policy input.

A shared comparison-configuration digest identifies the fixed baseline/oracle
pair. Variant replay manifests differ because they record different executable
components, while both variants require the same canonical scenario digest and
root seed. Serial and threaded batch runners isolate every
`(scenario, seed, variant)` run, restore input order, and must produce identical
event, terminal-state, and behavioral digests. Runtime executor details remain
diagnostics only.

The M0 confirmatory gate uses the 100 fixed benchmark seeds from 1000 through
1099. It passes only when mean paired oracle-minus-baseline viability AUC is at
least 0.02, the deterministic paired-bootstrap 95% lower bound is greater than
zero, and oracle irreversible errors do not exceed baseline errors. The paired
bootstrap uses root seed 20260827, named stream `analysis:paired-bootstrap`,
10,000 resamples, and 95% confidence. The manifest, thresholds, seeds, and
analysis are frozen before that benchmark.

## Consequences

The oracle cannot accidentally become a deployable controller, metrics remain
recomputable from event evidence, and worker scheduling cannot manufacture an
effect. A passing M0 gate demonstrates measurable headroom and a qualified
experimental substrate; it does not validate a later cognitive candidate.
