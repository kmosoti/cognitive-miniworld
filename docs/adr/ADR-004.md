# ADR-004 — JSONL canonical log, Parquet derived analytics

**Status:** accepted · **Date:** 2026-08-27

## Context

The event log is the evidence. It must be diffable, appendable, and
readable without the code that produced it, because metrics recompute
from events alone (MW-006) and results outlive the harness version that
generated them.

## Decision

Append-only JSONL is the canonical event log format in the first
release. Parquet is permitted only as a derived benchmark format once
experiment volume justifies it, and never as the source of truth.

## Consequences

Logs stay greppable and reviewable in a pull request. Canonical
encoding sorts keys at serialization boundaries so digests do not
depend on dict insertion order. A derived Parquet layer, when it
arrives, must be regenerable from the JSONL.
