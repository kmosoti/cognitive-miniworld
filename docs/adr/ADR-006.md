# ADR-006 — No emotion enums as control inputs

**Status:** accepted · **Date:** 2026-08-27

## Context

A `FearAgent` or an `AngerAgent` presupposes the conclusion. The project
hypothesis is the opposite: emotion-like policy differences should emerge from
continuous appraisal dimensions, and a
categorical module would make that untestable by construction.

## Decision

Control inputs are continuous appraisal dimensions — goal relevance,
expected harm and benefit, certainty, imminence, controllability,
agency, novelty, urgency, approach/avoidance bias. Emotion labels are
optional diagnostic projections of that vector, never inputs to
control and never branch conditions.

## Consequences

MW-050's acceptance requires same-valence scenarios with different
controllability or certainty to produce different policies. Any label
emitted for human consumption must be derivable from the appraisal
vector and removable without changing behavior.
