# ADR-029 — State-relative outcome value and the endogenous-regulation gate

**Status:** accepted · **Date:** 2026-08-29 · **Source:** MW-021

## Context

MW-021 requires the same resource outcome to have different marginal value
under deprivation, sufficiency, and excess, without introducing a universally
positive reward constant. ADR-014 already defines regulatory error as squared
normalized deviation from a fixed reference point, and MW-014's arbitrator
already used the reduction in that error as `reference_progress`. A separate
reward table would duplicate that rule and could drift from arbitration.

The MW-020 controller selected `consume` from a forecast deficit. Closing M2
requires its action to be selected from the state-relative value itself, while
keeping ADR-028's fixture, seeds, fixed-setpoint baseline, primary threshold,
safety margin, anticipation deadline, and reference-sensitivity gates fixed.

## Decision

For reference points `j = 1..m`, current belief hypotheses `X`, predicted
outcomes `Y`, priority `p`, target `r_j`, and tolerance `t_j > 0`, define

```text
L(Z) = E[(1/m) sum_j ((Z_j - r_j) / t_j)^2]
V(X -> Y) = p (L(X) - L(Y)).
```

Positive value means the outcome reduces reference deviation; zero means it
leaves deviation unchanged; negative value means it increases deviation. The
target is held fixed while comparing endpoints. Negative values are preserved,
not clipped. `StateRelativeOutcomeValuator` owns this arithmetic, and the
action arbitrator calls the same implementation for `reference_progress`.

The public-contract boundary accepts a `BeliefState`, a matching
`PredictionDistribution`, a same-tick `ResourceBudget`, and the prediction-
horizon points of a `ReferenceTrajectory`. It requires exact belief and horizon
cross-links, unique evaluated features, finite numeric values, bounded item and
feature counts, a sorted provenance union, and sufficient deterministic compute
budget. Its detailed receipt is internal rather than a new wire contract, so
the 15 frozen public schemas do not change.

For the MW-020 adapter, the visible presence of a resource enables an explicit
conservative action-model probe of `q = 1.0` energy unit at the forecast
horizon. This is not the hidden resource yield and does not read the schedule,
world state, or resource quality. The controller consumes exactly when the
resource is visible and

```text
V(x -> x + q) > 0.
```

Every action records the probe outcome and signed marginal value. Evidence
requires all pre-consume values to be nonpositive and the consume value to be
positive. ADR-028's behavioral and safety thresholds remain unchanged.

The preregistered analytical contrast holds `r = 50`, `t = 10`, `p = 1`, and
the identical resource amount `q = 20` fixed. It evaluates `x = 20, 40, 80`
against an evaluator-only fixed-positive `+1` ablation. The candidate must
produce positive, zero, and negative values with spread at least `20`; the
ablation spread must remain `0`.

For deterministic `q > 0`, the implementation equation reduces to

```text
V / p = q (2 (r - x) - q) / t^2.
```

Therefore the sign changes exactly at `x = r - q/2`; it is equivalent to
whether the outcome is closer to the fixed reference. Zero change has zero
value, endpoint reversal negates value, translation leaves value unchanged,
and positive rescaling of state, target, outcome, and tolerance leaves value
unchanged. Expectation is linear, priority scales value, and the multi-variable
rule is the declared arithmetic mean.

## Confirmatory result

Across the three-state contrast, candidate values were exactly `8.0`, `0.0`,
and `-16.0`; fixed-positive ablation values were `1.0`, `1.0`, and `1.0`.
Candidate and ablation spreads were `24.0` and `0.0`.

Across benchmark seeds 1000–1099, the composed controller consumed at tick `8`.
Its minimum consume value was `0.00125`, maximum pre-consume value was
`-0.0175`, minimum time-outside improvement remained `3.0` ticks, mean
viability-AUC difference remained `0.014634146341463402`, and irreversible-
error increase remained `0.0`. The composed demand-shift evidence SHA-256 is
`82b5a394f7ba20420c0b9d679ab28af7f2f0591ae13dd500402018711fd4c015`.

## Consequences

Outcome value is a signed relationship among a state, predicted endpoint, and
fixed context-sensitive reference; resources have no universal valence. M2 is
closed only for the canonical demand-shift fixture and analytical contrast.
Learned action effects, multiple resource types, or risk-sensitive nonlinear
valuation require new preregistration and evidence.
