# ADR-007 — Typed error vector instead of one global scalar

**Status:** accepted · **Date:** 2026-08-27

## Context

Prediction error and control error imply different updates: one revises
a model, the other changes an action. Collapsing sensory, control,
outcome, timing, agency, and learning-progress signals into a single
scalar destroys the information needed to route a learning update, and
makes credit assignment guesswork.

## Decision

`ErrorDecomposer` emits distinct channels — sensory, control, outcome,
timing, agency, and learning-progress — and learners subscribe to the
channels they are entitled to. A scalar-error implementation remains
available strictly as an ablation baseline. No single global reward
scalar stands in for every learning and control signal.

## Consequences

Expected-but-undesirable and unexpected-but-safe fixtures must produce
visibly different bundles (MW-012). Mutation tests deliberately swap
prediction and control errors to confirm the distinction is load
bearing rather than cosmetic.
