# ADR-021 — Exact tabular state-estimation and calibration gate

**Status:** accepted · **Date:** 2026-08-28 · **Source:** MW-010

## Context

The first core primitive must fuse noisy public observations without importing
evaluator truth, adding a learned model, or changing the frozen `BeliefState`
contract. Its comparison must distinguish calibrated probability from merely
copying the newest sensor value, and contradictory evidence must be able to
dislodge a strong historical prior.

## Decision

The state estimator is an exact finite-state Bayesian filter. Each configured
variable declares a finite scalar domain, a symmetric one-tick persistence
model, a categorical observation-accuracy ceiling, and an optional normalized
prior. The joint posterior enumerates at most 256 states. Delayed observations
are marginalized through the same symmetric transition model; no hidden world
type, global randomness, or mutable implementation state enters the filter.

The partial-observability gate is frozen to a balanced two-state hidden Markov
trace with 40 ticks, persistence `0.9`, observation accuracy `0.7`, and paired
seeds 1000–1099. Evaluator-owned latent transitions and sensor emissions use
independent named streams `experiment:partial-observability:latent` and
`experiment:partial-observability:observations`. The primary metric is binary
Brier loss. The candidate-minus-ablation effect is baseline loss minus candidate
loss; it must be at least `0.02`, with a 95% paired-bootstrap lower bound above
zero. The bootstrap uses root seed 20260828, stream
`analysis:paired-bootstrap`, and 10,000 resamples. Perfect evaluator truth is the
zero-loss oracle ceiling.

A separate stale-memory gate starts from posterior probability `0.99` on the
old value. Repeated accuracy-`0.7` contradictory readings must make the new
value more probable within four ticks. Every emitted posterior must normalize
within `1e-12`.

## Consequences

MW-010 can be evaluated against the existing last-observation ablation without
a contract or dependency change. This isolated estimator does not choose an
action, so the gate makes no standalone viability claim; downstream policy
safety remains a noninferiority requirement when MW-013/MW-014 compose beliefs
into actions. A larger state space, asymmetric learned transition model, or
neural estimator requires a later issue and fresh preregistration.
