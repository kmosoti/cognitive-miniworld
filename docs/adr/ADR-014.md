# ADR-014 — ReferenceTrajectory shape

**Status:** accepted · **Date:** 2026-08-27

## Context

The source schematic contributes the constraint that targets may be
trajectories, not fixed set points. Milestone 0 ships only a static
provider, but Milestone 2's dynamic generator must slot in without
changing the contract — otherwise the comparison is confounded by a
schema change.

## Decision

A trajectory is a sequence of `(variable, target, tolerance,
horizon_tick)` points. Tolerance is the gain analog from the source
schematic: the arbitrator's deviation cost term is
`((x - target) / tolerance)^2`. The `StaticReferenceProvider` emits
constant targets at resource-range midpoints with fixed tolerance.

## Consequences

MW-020 and MW-021 compete for the same slot later without a contract
change, so the demand-shift comparison isolates the mechanism. Tight
tolerance means high gain; the arbitrator needs no separate gain field.
Reference provenance (which state estimate and forecast produced each
trajectory) is required from MW-020 onward.
