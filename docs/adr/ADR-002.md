# ADR-002 — Explicit RNG streams and event-sourced replay

**Status:** accepted · **Date:** 2026-08-27 · **Source:** EPIC §16

## Context

Module-global randomness makes results irreproducible and couples
unrelated components: drawing one extra sample in the observation noise
path silently shifts every later world draw. Ablation comparisons
demand that removing a primitive not perturb the world's realization.

## Decision

Every stochastic component receives an RNG object or immutable RNG
state; hidden module-global randomness is forbidden. Streams are named,
and a per-stream seed is derived as
`sha256(f"{root_seed}:{stream_name}")`, making streams independent by
construction. A run is replayable from its scenario manifest, root
seed, component versions, and event log, reproducing identical event
digests and terminal-state hash.

## Consequences

`src/cmw/rng.py` (MW-003) is the only randomness entry point. Wall
clock, `uuid4`, and `os.urandom` are excluded from all digests and from
`src/cmw/` entirely; ruff bans the `random`, `uuid`, and `numpy.random`
imports so the invariant fails at lint time, not at review time.
Replay mismatch is a CI failure.
