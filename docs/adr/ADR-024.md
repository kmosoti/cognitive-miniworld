# ADR-024 — Public typed-error decomposition and disagreement gate

**Status:** accepted · **Date:** 2026-08-28 · **Source:** MW-012

## Context

MW-012 must turn a completed public forecast into separately routable errors,
preserve the frozen `ErrorBundle`, and expose scalar collapse as an executable
ablation. ADR-007 distinguishes model correction from control correction, while
ADR-013 defines agency as attempted-versus-executed action mismatch. The
channel calculations and confirmatory disagreement fixtures were not yet
frozen.

## Decision

For each numeric reference variable at the prediction horizon, the decomposer
uses its tolerance to normalize absolute differences. Sensory error compares
the forecast expectation with the latest latency-adjusted observation; state
revision compares prior and revised belief expectations; control error compares
the revised belief with the reference; and outcome error compares the revised
belief with the forecast. Timing is the mean absolute gap between effective
observation tick and forecast horizon. Agency is the binary efference-copy
mismatch from ADR-013. Learning progress is prior sensory error minus current
sensory error, or `0.0` when no prior error exists. Provenance unions every
public input event, confidence takes the minimum source confidence, and bounded
input/work limits reject ambiguous or excessive comparisons.

The scalar ablation is the mean absolute magnitude of the six numeric
`ErrorBundle` fields plus binary agency, erasing channel identity. A model
update subscribes to sensory or outcome error; a control response subscribes
to control or agency error. The named-stream fixtures vary magnitude while
holding causal structure fixed: expected-but-undesirable is predicted correctly
and requires control but no model update; unexpected-but-safe violates the
forecast and requires a model update but no control response. Across the frozen
100 benchmark seeds, typed credit precision must exceed scalar precision by at
least `0.5`, with zero unnecessary typed control responses. The scalar arm must
over-route both a model update in the first fixture and a control response in
the second. An evaluator-only fixed action adapter turns necessary control into
restorative `rest` and unnecessary control into costly `inspect`; viability AUC
is recomputed from canonical state events and typed routing must be noninferior
to scalar routing.

## Consequences

No contract schema changes. The first implementation is intentionally limited
to numeric variables with an exact-horizon reference and a public efference
copy. Whole-episode action arbitration and viability effects remain MW-014
scope beyond this fixed safety adapter; changing formulas, routing
subscriptions, fixtures, stream, action adapter, or thresholds requires a new
decision record.
