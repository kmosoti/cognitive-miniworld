# ADR-009 — Biological evidence and engineering analogy are different relation types

**Status:** accepted · **Date:** 2026-08-27

## Context

"The brain does X, so our module does X" is the failure mode this
project most needs to avoid. The knowledge graph must not let a bounded
neuroscience claim silently become a claim about a Python class.

## Decision

The JSON-LD graph keeps these as distinct relation types.
`cmw:supports` means a bounded source claim constrains or motivates a
primitive — never that the module is biologically identified with the
source mechanism. Every `cmw:EvidenceClaim` carries its source,
evidence class, epistemic status, and scope limit; project hypotheses
are `cmw:CandidateTheory`, not evidence.

## Consequences

`knowledge/validate_graph.py` enforces the required fields, the
supports/supportedBy and tests/testedBy symmetry, and range typing; it
runs in CI from MW-001 and exits 2 on violation. Every implemented
primitive must trace through the graph to bounded claims, source scope,
experiments, metrics, and failure modes.
