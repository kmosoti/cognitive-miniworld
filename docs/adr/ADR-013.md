# ADR-013 — Agency error channel

**Status:** accepted · **Date:** 2026-08-27

## Context

"The world surprised me" and "I did not do what I intended" call for
different updates: the first revises the forward model, the second
revises beliefs about preconditions and control. ADR-007 requires the
channels to stay distinct.

## Decision

Agency error is the mismatch between the efference copy — the action
attempted — and the action the world actually executed, whether through
precondition failure or slip. It is a binary mismatch in the first
release. It is distinct from outcome error, which is the world
responding differently than predicted to the action that *did* execute.

## Consequences

The efference copy is an observation channel, so the agent can compute this
without hidden state. A graded agency signal is a later refinement and needs an
ADR. Hidden-precondition fixtures are the natural test: they must raise agency
error, not outcome error.
