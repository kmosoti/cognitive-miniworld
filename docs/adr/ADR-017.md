# ADR-017 — Telemetry channel and digest boundary

Status: accepted

## Context

Milestone 0 metrics must be reproducible from the event log while evaluator-only
truth remains unavailable to agents. Runtime diagnostics are useful for
qualifying Python 3.14 free-threading, but interpreter details, executor choice,
worker count, scheduling, and wall time cannot alter behavioral identity.

## Decision

The canonical event log is newline-delimited `CanonicalEvent` data written
through an exclusive-create, append-only API. Sequence numbers are contiguous,
ticks are monotonic, every line is canonically encoded, and bounded readers
reject malformed or oversized input.

Event kinds belong to an explicit `agent` or `evaluator` channel. Unmarked
system-shaped records are classifiable for diagnostics but fail closed at the
telemetry boundary. Evaluator ground truth uses reserved `actual_*` fields and
is rejected from agent-channel events. Metrics consume canonical events only;
they never import a controller, primitive implementation, or hidden
`WorldState`.

Viability is sampled exactly once at tick zero and every subsequent episode
tick; the final sample closes the episode. Missing or duplicate ticks invalidate
the metric rather than silently changing its weighting.

A run summary records the scenario manifest hash, configuration hash, component
versions, paired-seed comparison identity, and metric values. Interpreter,
version, ABI, GIL state, executor, and worker count live in a separate runtime
diagnostics value. The behavioral summary digest is computed from the summary
without diagnostics.

Comparison identity is a deterministic digest of the shared scenario and
comparison configuration. Pair identity adds the shared root seed. Baseline and
candidate manifests may differ, but identical paired seeds remain explicit
without relying on variant names, filenames, or wall time.

## Consequences

Any metric accepted at a verdict can be recomputed from the sealed JSONL log.
Agent-facing code cannot mistake evaluator truth for an observation, and
changing machines or worker counts cannot change behavioral hashes. Diagnostic
comparisons remain possible through a deliberately nonbehavioral side channel.
