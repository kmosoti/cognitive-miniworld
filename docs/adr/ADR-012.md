# ADR-012 — Compute–time coupling

**Status:** accepted · **Date:** 2026-08-27

## Context

Metacontrol (MW-031) is only meaningful if thinking costs something the
world notices. Charging wall time would make runs irreproducible and
machine-dependent, violating the deterministic-time boundary.

## Decision

Each tick grants a fixed compute allowance `C` in abstract units. Every
primitive invocation reports a declared, deterministic unit cost —
per-operation constants carried in the contract, never wall time. If
cumulative spend in a tick exceeds `C`, the world auto-advances
`ceil((spent - C) / C)` ticks with an implicit `wait` before the chosen
action executes.

## Consequences

Deliberation costs world time, deterministically: an agent that thinks
too long finds the world has moved on, and a slow machine produces the
same trajectory as a fast one. Unit-cost fields enter the contracts at
MW-002 so later milestones do not force a schema break. Telemetry may
still record wall time for diagnostics; it is excluded from all
digests.
