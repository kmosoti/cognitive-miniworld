# ADR-003 — Immutable typed contracts between primitives

**Status:** accepted · **Date:** 2026-08-27

## Context

Primitives are engineering hypotheses to be ablated and swapped. If one
reaches into another's state, the ablation is not clean and the central failure
question—was something observed, estimated, predicted, valued, or acted on
incorrectly?—becomes unanswerable.

## Decision

Primitives exchange `msgspec.Struct` messages declared `frozen=True`,
`kw_only=True`, with a mandatory `schema_version` field. Belief and
prediction contracts carry provenance and uncertainty as non-optional
fields. Contracts expose outputs, uncertainty, and provenance — never
implementation internals.

## Consequences

Serialization is stable and digestible, so contracts can be hashed into
the event log. Round-trip losslessness and rejection of hidden mutable
references are contract tests (MW-002). Any contract change after
MW-002 requires a new ADR.
