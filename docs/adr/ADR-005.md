# ADR-005 — No LLM in the core cognitive loop

**Status:** accepted · **Date:** 2026-08-27

## Context

A language model in the loop would make every result untraceable to a
specific mechanism, non-deterministic, and expensive to ablate. The
program tests nonlinguistic primitives; a system that "looks
intelligent" because it emits fluent text does not answer whether a primitive
caused a measurable improvement over its baseline.

## Decision

No LLM appears in the core milestones (MW-001..MW-051). A language
adapter is deferred to MW-062, tested only as core versus
core-plus-language with measured incremental task-grounded value.

## Consequences

Every core decision is explainable from typed contracts and the event
log. Determinism and replay remain achievable. The nonlinguistic loop
must pass all required gates before language is considered at all.
