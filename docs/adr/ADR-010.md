# ADR-010 — Hermetic boundary

**Status:** accepted · **Date:** 2026-08-27 · **Source:** KICKOFF

## Context

A lab that imports from a sibling project inherits that project's
release cadence, its bugs, and its determinism guarantees. Replay must
depend only on artifacts committed here.

## Decision

This repo is a standalone lab. No imports from, or dependencies on, any
other project. Verdicts and event logs are plain JSONL so results can
be exported later. Approved dependencies are `uv`, `ruff`, `ty`,
`pytest`, `hypothesis`, and `msgspec`, plus `numpy` only where a
distribution genuinely requires it. Revisit after Milestone 2.

## Consequences

Anything the harness needs, the harness contains. Integration happens
by exporting logs, not by linking code. A new dependency requires an
ADR and Kennedy's sign-off.
