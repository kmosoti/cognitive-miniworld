# MW-040 — Episodic recorder

**Verdict:** accepted on 2026-08-28 in package 0.13.0 under ADR-026's frozen gate.

**Complete record.** Each immutable episode retained sorted context, the full
belief, references, proposals and matching predictions, the selected action
decision, public outcomes, typed error channels, and canonical union
provenance. Eligibility stayed empty for MW-041 rather than inventing causal
credit.

**Explainable retrieval.** Every result exposed exact, conflicting,
query-only, and record-only feature evidence. Exact current context scored
`1.0`; the cue-matched but regime-conflicting stale record scored `0.5` and
never won a tie-break.

**Decision delta.** Across seeds 1000–1099, retrieval-supported binary decision
quality was `1.0` versus `0.45` for the fixed no-retrieval `wait` policy, a
mean paired delta of `0.55` over the `0.4` threshold. Stale selection rate was
`0.0`, and both action outcomes were exercised.

**Evidence.** The 100 seed-bound traces were unique. Canonical 50,172-byte
evidence SHA-256 was
`5d8ea84f5442303b3e9e71e384b8971c386a729c03ab1cb92bf5dfbdf26e98fb`.

**Deviation:** none; the decision adapter is evaluator-only, consolidation is
MW-042, and causal eligibility is MW-041.

**M1 optimization addendum (ADR-027, 2026-08-28).** Storage revalidation was
quadratic in occupancy: filling to the declared capacity of 256 took 10.1s
(~n^1.9) and one query 92ms. Validation now happens at construction, decode,
and encode boundaries only; retrieval constructs matches for returned results
alone, and the construction cap is derived from the admission bound so a full
memory is always queryable — previously storage admitted records that made
every later query exceed the retrieval work limit. Retrievals retain a compact
receipt for every scanned record and bind `unit_cost` to the exact scan plus
returned-record construction work under separate caps. A deterministic
snapshot commitment shared with the source recorder makes omission visible
without copying the full memory into each result. Fill dropped to 0.13s (77x,
~n^1.1) and a query to 9ms. Behavior, ordering, and scores are unchanged; the
canonical evidence digest above reflects this receipt, and all 528 tests pass.
