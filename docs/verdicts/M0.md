# Milestone 0 — Foundation and reproducibility

**Verdict:** passed on 2026-08-27. Promote the experimental substrate; do not
infer that any later cognitive primitive has passed. This verdict closes work at
the Milestone 0 boundary before MW-010.

## What exists

Package 0.7.0 is a deterministic, event-sourced experiment laboratory on
CPython 3.14.7 free-threaded. It contains immutable public contracts, isolated
named RNG streams, canonical event logs and replay, the ViabilityGrid world,
seven preregistered fixtures, event-only metrics, four executable baselines, an
evaluator-confined demand-shift oracle, bounded serial/threaded runners, and a
strict typed M0 gate. Serial, two-worker, and four-worker executions produce
identical ordered event, terminal-state, and behavioral digests.

## Reproduce

Create and verify the deterministic replay demonstration:

```bash
cmw_demo_dir="$(mktemp -d)/run"
uv run --locked python -m cmw.replay --write-demo "$cmw_demo_dir"
uv run --locked python -m cmw.replay "$cmw_demo_dir"
```

Run the frozen M0 comparison into a new exclusive evidence path:

```bash
cmw_evidence_dir="$(mktemp -d)"
uv run --locked python -m cmw.demo --tier benchmark --workers 4 \
  --evidence "$cmw_evidence_dir/m0-evidence.jsonl.gz"
sha256sum "$cmw_evidence_dir/m0-evidence.jsonl.gz"
```

The verdict run used CPython 3.14.7 with `sys._is_gil_enabled() == False`.
Before it ran, Ruff, ty, all 370 tests, source/wheel builds, and graph validation
passed; the graph retained its known predicate-overload warning and zero
failures. Independent review returned `APPROVE` before the benchmark budget was
consumed.

## Deviations and limits

- ADR-015 supersedes the original Python 3.12 plan with exact
  CPython 3.14.7 free-threaded plus a conventional compatibility lane.
- Only demand-shift viability AUC is a Milestone 0 scientific result. Metrics
  requiring state estimates, predictions, credit assignments, attention
  decisions, or self-estimates remain unclaimed until the corresponding
  candidate milestone.
- The oracle result establishes measurable experimental headroom, not evidence
  for consciousness, general intelligence, or the merit of a future candidate.
- The evidence graph still reports the previously documented overloaded
  `cmw:tests` predicate warning; it has no dangling references or validation
  failures.
