# MW-012 — Typed error decomposer

**Verdict:** accepted on 2026-08-28 in package 0.11.0 under ADR-024's frozen gate.

**Channels.** Public forecast, belief, reference, observation, timing, efference, and prior-error inputs produced separately computed sensory, state-revision, control, outcome, timing, binary agency, and learning-progress fields without changing `ErrorBundle`.
**Contrasts.** Expected-but-undesirable routed control but no model update; unexpected-but-safe routed a model update but no control response. Their typed bundles were distinct for every seed.
**Ablation.** The executable scalar absolute-error baseline collapsed channel identity, over-routing one model update and one unnecessary control response per paired fixture.
**Evidence.** Across seeds 1000–1099, normalized fixture magnitudes covered `1.0`, `2.0`, and `3.0`; typed credit precision was `1.0` versus scalar `0.5`, typed viability AUC was `0.225` versus `0.175`, and typed unnecessary control count stayed `0`.
**Digest.** Canonical 73,248-byte evidence SHA-256 was `abed79ae711d739e7ae459a251afc3b881c5b77085796f078b9d163496fd4f93`, with 100 unique seed-bound traces.
**Deviation:** none; the fixed evaluator action adapter is evidence-only, and reusable arbitration remains MW-014.
