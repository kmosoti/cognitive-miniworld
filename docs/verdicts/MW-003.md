# MW-003 — Explicit RNG and deterministic replay

**Verdict:** complete. Package 0.3.0 adds independent SHA-256-derived named
SplitMix64 streams, canonical event/state records, sealed run directories, and
`python -m cmw.replay <run_dir>`.

**Replay evidence.** The demo re-created 3 events with event-log hash
`e7ffcfa68bd70e805d9f39ed52c85a3499cadbf3cf8d12bdd8a8dab555436908` and
terminal hash `d5292427ba0ce1ca5a023ff031d0c1c874f641eaf64af026fbbe618029efed5b`;
a second replay produced the same hashes. Event, manifest, terminal, summary,
noncanonical-encoding, sequence, and tick-order tampering all fail closed.

**Stream isolation.** Hypothesis reorders unique named streams and schedules
them concurrently; every per-stream sequence remains identical. An
alias-aware architecture test rejects hidden RNG, wall-clock, UUID, and entropy
calls anywhere under `src/cmw/`.

**Gates.** Ruff, ty, lock check, source/wheel builds, and the evidence graph
passed. The free-threaded lane passed 55 tests; conventional 3.14.7 passed 52
applicable tests with 3 GIL-specific tests deselected. **Deviations:** none.
