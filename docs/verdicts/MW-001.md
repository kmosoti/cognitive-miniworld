# MW-001 — Repository and quality gates

**Verdict:** complete. Milestone 0 baseline is green.

**Built.** `uv` project (`cognitive-miniworld` 0.1.0, `uv_build`, src
layout, interpreter pinned to 3.12 via `.python-version`), committed
`uv.lock`, dev group `pytest`/`hypothesis`/`ruff`/`ty`, runtime dep
`msgspec`. `src/cmw/__init__.py` exposes `__version__` — the semantic
version destined for every run manifest. Gate tests in `tests/`,
GitHub Actions workflow `.github/workflows/ci.yml`, ADR-001..014 in
`docs/adr/` (001–009 from EPIC §16, 010–014 from KICKOFF, all
"accepted"), root `README.md`.

**Criterion 1 — locked environment runs every gate.** Verified in a
clean copy of the tree with no `.venv` and a fresh uv cache:
`uv sync --locked --all-groups` then `ruff check src tests`,
`ty check`, `pytest` (7 passed), and
`knowledge/validate_graph.py` (exit 0; 226 nodes, 124 complete paths,
~1864 triples, 1 warning). `--locked` makes a stale lock a CI failure.

**Criterion 2 — a failing property fails CI.**
`tests/test_quality_gates.py` runs pytest on a deliberately falsifiable
Hypothesis property under this repo's own config and asserts a non-zero
exit plus the shrunk counterexample; a second test asserts
`--strict-markers` rejects a typo'd marker, so no tier can silently
skip. `tests/test_graph_validator.py` asserts the committed graph exits
0 and that an injected dangling reference exits 2 — the graph gate can
go red.

**Deviations.** Two, both sequencing, neither weakening a criterion:
(a) the "replay" and "smoke" CI steps have no subject yet — the markers
are registered and CI runs `uv run pytest`, which collects every
marker, so MW-003's replay gates and MW-005's smoke runs fail this
workflow with no CI change; the `python -m cmw.replay` demo command
lands with MW-003. (b) Beyond lint config as specified, ruff bans the
`random`, `uuid`, and `numpy.random` imports inside `src/`, moving
EPIC §5 invariant 2 to lint time; the full call-level check belongs to
MW-003.

**Open question for Kennedy.** `validate_graph.py` warns that
`cmw:tests` is overloaded — `Experiment -> Primitive` (22) and
`Issue -> Experiment` (39). Treated as a review item, not noise: worth
a distinct predicate (`cmw:executes`) before the graph grows.
