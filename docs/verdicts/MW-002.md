# MW-002 — Canonical data contracts

**Verdict:** complete. Package version 0.2.0 exposes all 15 contracts assigned
to MW-002 by the knowledge graph, including ADR-014 reference points and
ADR-012 deterministic unit costs; no primitive behavior was added.

**Round trips.** Canonical deterministic JSON restores every concrete type
losslessly and re-encodes to identical bytes. A fixed snapshot and a
Hypothesis scalar property guard field order and value fidelity.

**Required evidence.** `BeliefState` and `PredictionDistribution` reject
payloads missing provenance or uncertainty. Every public value is a frozen,
keyword-only, versioned `msgspec.Struct`; tuple-only nesting plus constructor
validation rejects mutable lists, mappings, and mutable scalar payloads.

**Gates.** Twelve contract tests and 22 total free-threaded tests passed;
the conventional-GIL lane passed 19 applicable tests. Ruff, ty, both package
builds, and the evidence graph passed with its one previously recorded warning.

**Deviations:** none.
