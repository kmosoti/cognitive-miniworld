# MW-007 — Baselines and oracle

**Verdict:** accepted. Package 0.7.0 completes the executable baseline and
evaluator-only oracle boundary required for Milestone 0.

**Baseline coverage.** `cmw.agents` provides the reactive fixed-setpoint
controller, last-observation estimator, random-exploration baseline, and
prediction-error curiosity baseline. A closed registry covers all seven
first-wave fixtures, resolves every declared ID to a concrete implementation,
and invokes it through immutable public contracts and an explicit named RNG
where needed. These invocations prove an ablation is executable; they do not
manufacture later candidates or their measurements.

**Oracle isolation.** The demand-shift oracle is confined to
`cmw.experiments`, requires the exact canonical fixture digest and one-tick
action assumptions, and receives evaluator-owned world state. No oracle class
is exported from the agent or top-level experiment interface. Tests reject a
lookalike manifest even when it reuses the canonical label.

**Paired execution and evidence.** The bounded runner isolates
scenario/seed/variant executions, records policy configuration identity, emits
active public stimuli, preserves evaluator-only schedule records, and gives
serial, two-worker, and four-worker batches identical ordered behavioral
hashes. Stimulus schedule changes advance through a single immutable cursor;
per-run and aggregate admission limits reject excessive ticks, stimulus work,
schedule-event volume, and hidden world-schedule validation before compilation
or worker creation. The typed M0 evaluator validates every run, pair, replay,
metric, configuration, seed, bootstrap continuation, and safety count before
canonical evidence can be encoded.

**Verification.** Ruff, ty, source and wheel builds, 370 tests, and the
226-node evidence graph passed. An independent final review found no remaining
critical or high-severity MW-007/M0 blocker.

**Deviation.** Primary scores for the six later candidate-specific experiments
remain deferred until those candidates can emit their preregistered evidence.
ADR-019 makes that boundary explicit; the executable probes are coverage
evidence, not surrogate scientific results.
